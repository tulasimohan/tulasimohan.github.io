Running time of Ford-Fulkerson Algorithm

  • Let \(n\) be the number of nodes and \(m\) be the number of edges in \(G\). Since there is at least one edge incident on every node, \(m\geq n/2\).

  • Hence \(O(m+n) = O(n)\).

  • The while loop runs at most \(f^*\) iterations where \(f^*\) is the max flow value.

  • In each iteration a path is found in the residual graph which has at most \(2m\) edges.

  • If adjacency-list data structure is used to represent the graph, finding a path \(P\) using DFS or BFS takes \(O(m)\) time.

  • Augmenting takes \(O(n)\) times as it goes over at most \(n-1\) edges.

  • New residual graph can be constructed in \(O(m)\) time.

  • Thus, the total time complexity is \(O(mf^*)\).

The Edmonds-Karp Algorithm

The Edmonds-Karp Insight What makes Edmonds-Karp different?

  • Published by Jack Edmonds and Richard Karp in 1972 (independently discovered by Yefim Dinitz in 1970).

  • It specifies exactly how to find the augmenting path.

  • The Rule: Always choose the augmenting path with the fewest number of edges.

  • How: Find the path using Breadth-First Search (BFS).

Residual Networks To understand how we augment flow, we need the residual network \(G_f\).

  • The residual capacity \(c_f(u, v)\) is the additional flow we can push from \(u\) to \(v\).

  • Forward edges: \(c_f(u, v) = c(u, v) - f(u, v)\).

  • Backward edges: We can "undo" flow we already pushed. \(c_f(v, u) = f(u, v)\).

  • The BFS runs on \(G_f\), looking for any path from \(s\) to \(t\) where every edge has \(c_f > 0\).

Algorithm & Complexity

Algorithm Pseudocode

Initialize flow \(f(u, v) \gets 0\) for all edges \(c_f(p) \gets \min \{ c_f(u, v) : (u, v) \in p \}\) \(f(u, v) \gets f(u, v) + c_f(p)\) \(f(v, u) \gets f(v, u) - c_f(p)\) total flow from \(s\)

Time Complexity Total Time Complexity: \(\mathcal{O}(V E^2)\)

  • BFS Cost: Finding a shortest path takes \(\mathcal{O}(E)\) time.

  • Number of Augmentations: The key theorem of Edmonds-Karp states that the total number of flow augmentations is bounded by \(\mathcal{O}(VE)\).

  • Why? The shortest path distance from the source to any node in the residual graph increases monotonically. Each edge can become a "bottleneck" at most \(V/2\) times.

  • \(\mathcal{O}(E)\) per BFS \(\times\) \(\mathcal{O}(VE)\) augmentations = \(\mathcal{O}(V E^2)\).

Conclusion

Summary

  • Edmonds-Karp is a robust, fully polynomial-time implementation of the Ford-Fulkerson method.

  • By using BFS to find the shortest augmenting path (in terms of edge count), it avoids the pathological worst-cases of generic Ford-Fulkerson.

  • It is guaranteed to terminate and find the maximum flow, even for networks with irrational capacities.

  • It runs in \(\mathcal{O}(V E^2)\) time, making it practical for many real-world network flow problems.

Network Flow to Bipartite Matching

  • Given a bipartite graph \(G = (L, R, E)\), direct the edges from \(L\) to \(R\).

  • Add new vertices \(s\) and \(t\).

  • Add an edge from \(s\) to every vertex in \(L\).

  • Add an edge from every vertex in \(R\) to \(t\).

  • Make all the capacities \(1\). This completes the construction of \(G'\).

  • Solve maximum flow problem on the new flow network \(G'\).

Edges used in the maximum flow corresponds to the maximum matching.

Network Flow to Bipartite Matching

  • Suppose \(M\) is the maximum flow in \(G'\).

  • Because, capacities are integral, max flow will be integral.

  • Because the capacities are all \(1\)’s:

    • Either use an edge completely (sending \(1\) unit of flow)

    • or do not use the edge at all.

We will show:

  • \(M\) is a matching.

  • \(M\) is maximum.

\(M\) is a matching

  • We can choose at most one edge leaving any node in \(L\).

  • We can choose at most one edge entering any node in \(R\).

\(M\) is maximum

  • Suppose we find a maximum flow \(f^* = k\).

  • This corresponds to a matching \(M\) of size \(k\).

  • Suppose \(M\) is not maximum, and there is another matching \(M'\) of size greater than \(k\).

  • Then \(f^*\) is not maximum. This is a contradiction.

  • Thus \(M\) is maximum.

Time Complexity

  • Maximum value of the flow is \(n\) where \(|L|=n\).

  • The number of edges in \(G'\) is \(m + 2n\) where \(m\) is the number of edges in \(G\).

  • Using Ford-Fulkerson algorithm, the time complexity is \(O(mn)\).
