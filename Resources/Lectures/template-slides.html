Frame Pattern

Anatomy of a Frame Slide

The frame pattern is the primary slide style for Lectures 10 onward. Each slide is wrapped in a ::: frame div:

::: frame
## Slide Title

- Bullet point
- Another point
:::

Key rules:

  • The ::: frame wrapper creates a distinct slide boundary.
  • Use ## headings inside each frame for the slide title.
  • Place ::: on its own line to open and close the frame.

Frame with Math

Let \(A\) be an array of \(n\) distinct integers.

We want the \(k^{th}\) smallest element.

The recurrence for QuickSelect is:

\[T(n) \leq (n-1) + \frac{2}{n} \sum_{i=n/2}^{n-1} T(i)\]

Available MathJax macros (defined in _metadata.yml):

  • \bigo{n} → \(\bigo{n}\)
  • \bra{x + y} → \(\bra{x + y}\)
  • \pmone → \(\pmone\)
  • \reals → \(\reals\)
  • \zo → \(\zo\)
  • \ftwo → \(\ftwo\)
  • \eps → \(\eps\)

Frame with Theorem / Lemma / Proof

Lemma 1 (Cycle Property). Let \(C\) be any cycle, and let \(f\) be the maximum cost edge belonging to \(C\). Then the MST \(T^*\) does not contain \(f\).

Proof. Proof. Suppose \(f \in T^*\). Deleting \(f\) disconnects \(T^*\). Let \(S\) be one side of the cut. Some other edge \(e \in C\) has exactly one endpoint in \(S\), and \(T = T^* \cup \{e\} - \{f\}\) is a spanning tree of lower cost — a contradiction. ◻

Simple Separator Pattern

Separator Slides (Alternative Style)

The simple separator pattern (used in Lectures 1–9) uses *** to break slides, with ## for each slide title:

***

## Slide Title

Content here...

***

This is lighter-weight and useful for fast prototyping, but lacks the structural clarity of ::: frame blocks.

Algorithm: Karatsuba Multiplication

Idea: Reduce 4 recursive calls to 3.

Let \(a\), \(b\), \(c\), \(d\) be the four halves of two \(n\)-digit numbers.

  • \(ac\) — high product
  • \(bd\) — low product
  • \((a + b)(c + d) - ac - bd\) — cross term

\[T(n) = 3T(n/2) + O(n) = O(n^{\log_2 3}) \approx O(n^{1.585})\]

Asymptotic Notations

Notation Intuition Formal definition
\(O(g(n))\) Upper bound \(0 \leq f(n) \leq cg(n)\) for \(n \geq n_0\)
\(\Omega(g(n))\) Lower bound \(0 \leq cg(n) \leq f(n)\) for \(n \geq n_0\)
\(\Theta(g(n))\) Tight bound \(c_1 g(n) \leq f(n) \leq c_2 g(n)\)

Make sure to always specify which variable tends to infinity.

Code Blocks with Syntax Highlighting

Python with line numbers:

def quicksort(arr, lo, hi):
    if lo < hi:
        p = partition(arr, lo, hi)
        quicksort(arr, lo, p - 1)
        quicksort(arr, p + 1, hi)

C with fragment reveals:

int factorial(int n) {     // {.fragment}
    if (n <= 1) return 1;  // {.fragment}
    return n * factorial(n - 1); // {.fragment}
}                          // {.fragment}

Section Headers and Timeline

How Section Headers Work

Each # H1 heading creates:

  1. A section title slide in RevealJS.
  2. A timeline entry generated by timeline.lua.

The timeline shows all H1 headings as a horizontal nav strip, with the current section highlighted.
