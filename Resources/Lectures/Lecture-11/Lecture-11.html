Matrix Chain Multiplication

Matrix Multiplication

Matrix: An \(n\times m\) matrix \(A\) is a two dimensional array.

Matrix Multiplication

The product \(C=A\times B\) of a \(p\times q\) matrix \(A\) and a \(q\times r\) matrix \(B\) is a \(p\times r\) matrix given by \[\begin{aligned} c[i,j] &= \displaystyle\sum_{k=1}^q a[i,k]b[k,j] \end{aligned}\] for \(1\leq i\leq p\) and \(1\leq j\leq r\).

Matrix Multiplication

  • While \(AB\) is defined, \(BA\) might not be defined.

  • It is possible that \(AB\neq BA\).

  • Multiplication is defined recursively: \(A_1A_2...A_{n-1}A_n = A_1(A_2\cdots (A_{n-1}A_n))\).

  • Matrix multiplication is associative, e.g, \(A_1A_2A_3 = (A_1A_2)A_3 = A_1(A_2A_3)\). Thus, parenthesization does not change the results.

Complexity of direct matrix multiplication \(C = A_{p\times q}\times B_{q\times r}\).

  • \(C\) has \(pr\) entries and each entry takes \(\Theta(q)\) times to compute. So the total cost is \(\Theta(pqr)\).

Direct multiplication of \(A\), \(B\), and \(C\)

  • Given three matrices \(A_{p\times q}\), \(B_{q\times r}\), and \(C_{r\times s}\), we can compute \(ABC\) in two different ways:

    • \((AB)C :\) The number of multiplication needed is \(pqr + prs\).

    • \(A(BC) :\) The number of multiplication needed is \(qrs + pqs\).

  • Setting \(p=5, q=4, r=6,\) and \(s=2\), we get

    • Complexity of \((AB)C\) is \(180\).

    • Complexity of \(A(BC)\) is \(88\).

Significant difference!

Observation 1. Complexity of a series of matrix multiplication depends on ordering!

Matrix chain multiplication

Problem Definition: Given \(n\) matrices \(A_1, A_2, ..., A_n\) with dimensions \(p_0, p_1, ..., p_n\) such that the dimensions of \(A_i\) be \(p_{i-1}\times p_i\), find the “multiplication sequence" that minimizes the number of scalar multiplication in computing \(A_1A_2...A_n\).
Exhaustive search: \(\Omega(4^n/n^{3/2})\) - approximation of Catalan number \(\frac{1}{n+1}\binom{2n}{n}\).
Any Better approach?
Yes. Dynamic programming.

Dynamic Programming Algorithm

Optimal Substructure: Determine the structure of an optimal solution (a parenthesization in this case).
For each pair \(1\leq i\leq j\leq n\), determine the multiplication sequence for \(A_{i...j} = A_iA_{i+1}...A_j\) that minimizes the number of scalar multiplication.
Clearly, \(A_{i...j}\) is a \(p_{i-1}\times p_j\) matrix.

Dynamic Programming Algorithm

Parenthesization for \(A_{i...j}\): For any optimal multiplication sequence, at the last step, we are multiplying two matrices \(A_{i...k}\) and \(A_{k+1...j}\) for some \(k\). That is, \[\begin{aligned} A_{i...j} &= (A_i...A_k)(A_{k+1}...A_j) = A_{i...k}A_{k+1...j}. \end{aligned}\] Example: \(A_{3...6} = (A_3(A_4A_5))(A_6) = A_{3...5}A_{6...6}\).
Here, \(k=5\).

Dynamic Programming Algorithm

If the optimal solution of \(A_{i...j}\) involves splitting into \(A_{i...k}\) and \(A_{k+1...j}\) at the final step then parenthesization of \(A_{i...k}\) and \(A_{k+1...j}\) in the final optimal solution must also be optimal for the subproblems. Why?

  • If parenthesization of \(A_{i...k}\) was not optimal we could replace it by a better parenthesization and get a cheaper final solution, leading to a contradiction.

  • Similarly, if parenthesization of \(A_{k+1...j}\) was not optimal we could replace it by a better parenthesization and get a cheaper final solution, leading to a contradiction.

Dynamic Programming Algorithm

Define the value of an optimal solution to a subproblem: For \(1\leq i\leq j\leq n\), let \(m[i,j]\) denote the minimum number of multiplication required to compute \(A_{i...j}\). Then the optimal cost can be defined as follows: \[m[i,j] = \begin{cases} 0 & i=j,\\ \mbox{min}_{i\leq k<j}(m[i,k] + m[k+1,j] + p_{i-1}p_kp_j) & i<j \end{cases}\]

Proof. Proof. Any optimal sequence of multiplication for \(A_{i...j}\) is equivalent to some choice of splitting \(A_{i...j} = A_{i...k}A_{k+1...j}\) for some \(k\), where the sequence of multiplications for \(A_{i...k}\) and \(A_{k+1...j}\) are also optimal. Hence the formulation follows. ◻
