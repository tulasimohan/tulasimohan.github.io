# Personal Website

This repository contains the source code for my personal academic website built using Quarto.

## Structure

- `assets/` - Static assets (images, CSS, etc.)
- `docs/` - Generated website files
- `src/` - Source files for the website
  - `pages/` - Quarto markdown files for each page
  - `notes/` - Personal notes and documentation
- `index.html` - Main entry point
- `_quarto.yml` - Quarto configuration file

## Building

The website is built using Quarto. To build locally:

```bash
quarto render
```
