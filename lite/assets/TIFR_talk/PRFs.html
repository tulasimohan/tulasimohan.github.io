Candidate 1: Local PRFs (Goldreich)

A PRF is \(d\)-local if every output bit depends on exactly \(d\) bits of the seed.

{
  const width = 450;
  const height = 350;
  const svg = d3.select(DOM.svg(width, height));
  
  // Seed Nodes (Left) - n bits
  const seed = [1, 2, 3, 4, 5];
  svg.selectAll(".seed").data(seed).enter().append("circle")
    .attr("cx", 60).attr("cy", d => d * 60).attr("r", 12)
    .attr("fill", "#1a1a66");
  
  // Output Nodes (Right) - m bits
  const out = [0, 1, 2, 3, 4, 5, 6, 7];
  svg.selectAll(".out").data(out).enter().append("circle")
    .attr("cx", 340).attr("cy", d => d * 40 + 35).attr("r", 12)
    .attr("fill", "#4bb8d6");

  // Edges (d=3 locality)
  const links = [
    {s: 1, t: 0}, {s: 2, t: 0}, {s: 4, t: 0},
    {s: 2, t: 1}, {s: 3, t: 1}, {s: 5, t: 1},
    {s: 1, t: 2}, {s: 3, t: 2}, {s: 4, t: 2},
    {s: 2, t: 4}, {s: 4, t: 4}, {s: 5, t: 4},
    {s: 1, t: 7}, {s: 2, t: 7}, {s: 3, t: 7}
  ];
  
  svg.selectAll(".link").data(links).enter().append("line")
    .attr("x1", 72).attr("y1", d => d.s * 60)
    .attr("x2", 328).attr("y2", d => d.t * 40 + 35)
    .attr("stroke", "#cbd5e0")
    .attr("stroke-width", 1.5)
    .attr("opacity", 0.6);
    
  // Labels
  svg.append("text").attr("x", 60).attr("y", 25).attr("text-anchor", "middle")
    .style("font-weight", "bold").style("fill", "#1a1a66").text("Seed ($n$)");
  svg.append("text").attr("x", 340).attr("y", 25).attr("text-anchor", "middle")
    .style("font-weight", "bold").style("fill", "#1a1a66").text("Output ($m$)");
  
  return svg.node();
}
  • Expansion: Expand a seed of length \(n\) to \(m \gg n\) bits.
  • The Graph: Based on a highly expanding bipartite graph or combinatorial design.
  • The Predicate: Apply a simple function (like XOR or Majority) to the \(d\) incoming edges.
  • Why it matters: Cell sampling properties fail to compress these specific structures.

Candidate 2: LLU PRGs

LLU PRGs rely on the hardness of low-degree polynomials over finite fields.

  • The Construction: The seed determines the coefficients. The output is the evaluation of the polynomial at all points in the field.
  • The Trap: Data structure lower bounds (like KPI ’25) try to find linear dependencies or refutations.
  • Resilience: Low-degree polynomials are mathematically engineered to resist these exact algebraic attacks.
