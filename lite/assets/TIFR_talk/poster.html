The Barrier

A Natural Proof (Razborov–Rudich ’94) is a property \(\mathcal{P}\) of functions that is:

  • Largeness: \(|\mathcal{P} \cap H_n| / |H_n| \ge 1/2^{O(n)}\)
  • Constructivity: \(\mathcal{P}(f)\) is efficiently decidable
  • Usefulness: \(f \in \mathcal{P} \implies f \notin \text{CircuitClass}\)

Theorem [RR’94]: A natural proof against \(\mathcal{C}\) implies \(\mathcal{C}\) lacks strong PRFGs.

This Work: Natural Proofs for Data Structures

We port the Natural Proofs framework from circuit complexity to the cell probe model. We show that almost all major lower bound techniques are natural:

Setting Techniques Shown Natural
Static Cell Sampling, Richness, Round Elimination, Lifting, CNF Refutation
Dynamic Chronogram, Information Transfer, Chronogram + Cell Sampling, Chronogram + Weak Simulation

Consequence: All natural techniques (encompassing all known methods except one) cannot improve beyond the current state of the art.

Current State of the Art

Lower Bound Upper Bound
Static \(t = \tilde{\Omega}(\log \log M)\) \(t = O((\log M)^c)\)
Dynamic \(\max(t_q, t_u) = \tilde{\Omega}(\log^2 n)\) \(t = O(\text{polylog}(n))\)

The gap is exponential — our framework explains why closing it requires non-natural techniques.

PRF Candidates

Local PRFs (Static): Goldreich-style PRFs where each output bit depends on \(d\) seed bits via an expanding bipartite graph. Fool cell-sampling distinguishers.

LLU PRFs (Dynamic): Based on low-degree polynomials over finite fields. Resist algebraic attacks from chronogram + weak simulation techniques.

Conjecture: Both families are \((s,\epsilon)\)-secure for parameters just above state-of-the-art lower bounds.

How to Break the Barrier

  • Option 1: Develop non-natural techniques (e.g., lifting, KRW)
  • Option 2: Attack our PRF candidates directly
    • The KPI ’25 lower bound itself emerged from attacking local PRGs!
