Lesson Plan: Lecture 02 — Probability Review I: Random Variables & Expectation

[!note] Learning Objectives - Recall core probability concepts (sample spaces, events, axioms). - Define discrete and continuous random variables and mathematical expectation. - Understand and apply Linearity of Expectation (specifically for non-independent variables using Indicator RVs).

📝 Key Board Work & Formulas

1. Expectation & Linearity

  • Expectation definition (discrete): E[X] = \sum_{x} x \cdot \Pr[X = x]
  • Linearity of Expectation Theorem: For any random variables X_1, X_2, \dots, X_n (independent or not): E\left[\sum_{i=1}^n X_i\right] = \sum_{i=1}^n E[X_i]

2. Indicator Random Variables

  • For an event A, let: X_A = \begin{cases} 1 & \text{if } A \text{ occurs} \\ 0 & \text{otherwise} \end{cases}
  • Fundamental Lemma: E[X_A] = 1 \cdot \Pr[A] + 0 \cdot \Pr[\bar{A}] = \Pr[A]

3. Worked Example: Fixed Points in Permutations

  • Let \pi be a random permutation of \{1, 2, \dots, n\}. What is the expected number of fixed points (elements i such that \pi(i) = i)?
  • Let X be the number of fixed points. Let X_i be the indicator that \pi(i) = i.
  • X = \sum_{i=1}^n X_i
  • E[X_i] = \Pr[\pi(i) = i] = \frac{1}{n}
  • By linearity: E[X] = E\left[\sum_{i=1}^n X_i\right] = \sum_{i=1}^n E[X_i] = n \cdot \frac{1}{n} = 1
  • Key takeaway: The expected number of fixed points is exactly 1, regardless of n. Note that X_i and X_j are highly dependent, yet linearity holds!

❓ Concept Checks & Interactive Questions

  1. Expectation with Balls & Bins: > Question: “Suppose we throw n balls independently and uniformly at random into n bins. What is the expected number of empty bins?” > Answer: > - Let X be the number of empty bins. Let X_i be the indicator that bin i is empty. > - A bin i is empty if all n balls miss it. The probability that a single ball misses bin i is 1 - 1/n. > - Since the balls are thrown independently, the probability that all n balls miss bin i is: > \Pr[\text{bin } i \text{ is empty}] = \left(1 - \frac{1}{n}\right)^n > - By linearity: > E[X] = \sum_{i=1}^n E[X_i] = n \cdot \left(1 - \frac{1}{n}\right)^n > - As n \to \infty, this approaches: > n \cdot e^{-1} \approx 0.368 n > - Pedagogical Tip: Highlight that about 36.8% of the bins are expected to remain empty.
