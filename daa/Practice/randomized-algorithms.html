Randomized Algorithms

CS F364 — Design & Analysis of Algorithms | Summer 2026

Las Vegas vs Monte Carlo, Freivalds’ algorithm, fingerprinting, Schwartz-Zippel, Karger’s min-cut, boosting

← Practice

NoteProblem E1

Distinguish Las Vegas and Monte Carlo randomized algorithms. Give one example of each type from the course.

TipSolution

Las Vegas: always correct, randomized runtime (e.g., randomized quicksort). Monte Carlo: bounded error, deterministic runtime (e.g., Freivalds’ algorithm).

NoteProblem E2

Freivalds’ algorithm for checking AB = C picks r \in \{0,1\}^n uniformly and checks A(Br) = Cr. If AB \neq C, what is the maximum probability that the test passes (false positive)? Assume all arithmetic is mod a prime p > 2.

TipSolution

If AB \neq C, then D = AB - C \neq 0 is a non-zero matrix. The test passes if Dr = 0 for random r \in \{0,1\}^n. Since D \neq 0, there is at least one non-zero row. For a non-zero row vector d \neq 0, \Pr[d \cdot r = 0] \le 1/2. So overall \Pr[Dr=0] \le 1/2.

NoteProblem E3

Alice and Bob have strings x, y \in \{0,1\}^n. They want to check equality using O(\log n) communication. Describe a randomized protocol using fingerprinting with a random prime. Analyze:

  1. The communication cost.
  2. The probability of error.
  3. How to reduce error to < 2^{-30}.
TipSolution

Choose a random prime p in range [2, M]. The fingerprint is x \bmod p. Send p and (x \bmod p). Cost: O(\log M + \log p) = O(\log n) bits. Error: probability p divides x-y which is at most n/\pi(M) \approx n \log \log M / \log M. For M = n^2, error \approx 1/n. To get < 2^{-30}, use k = 30/\log n independent primes or repeat.

NoteProblem E4

Let p(x_1,\dots,x_n) be a non-zero polynomial of degree d over a field \mathbb{F}. The Schwartz-Zippel Lemma states that for r_1,\dots,r_n chosen uniformly from a finite set S \subseteq \mathbb{F}:

\Pr[p(r_1,\dots,r_n) = 0] \le \frac{d}{|S|}

Use this to design a randomized algorithm for checking if a given bipartite graph G has a perfect matching via the Tutte matrix. What is the error probability?

TipSolution

Tutte matrix T: entry T_{ij} = x_{ij} if (i,j) \in E (with i < j) and T_{ij} = -x_{ji}, else 0. For bipartite graph, assign variable x_{ij} to each edge. \det(T) is a non-zero polynomial iff the graph has a perfect matching. By Schwartz-Zippel, evaluate at random points in a field of size q, error \le d/q where d \le n is degree of determinant.

NoteProblem E5

You are given three n \times n matrices A, B, C. You want to verify AB = C. Describe Freivalds’ algorithm. Now suppose you run the test k times independently. What is the error probability after k runs? How many runs are needed to achieve error < \epsilon?

TipSolution

Freivalds: pick r \in \{0,1\}^n, check A(Br) = Cr. Error per test \le 1/2. After k independent tests, error \le (1/2)^k. For error < \epsilon, need k > \log_2(1/\epsilon).

NoteProblem E6

Karger’s randomized min-cut algorithm repeatedly contracts a uniformly random edge until two vertices remain. The number of edges between them is a candidate min-cut value.

  1. Show that the probability that a specific min-cut survives one contraction is at least 1 - 2/n.
  2. Show that the probability that it survives all n-2 contractions is at least \binom{n}{2}^{-1}.
  3. How many repetitions are needed to find the min-cut with high probability?
TipSolution
  1. A specific min-cut has c edges. Probability a randomly chosen edge is in the cut: c/|E|. Min-cut has at most 2c/n edges (by handshake lemma style argument). Survival probability \ge 1 - 2/n.
  2. After n-2 contractions: \prod_{i=3}^n (1 - 2/i) = \prod_{i=3}^n (i-2)/i = 2/(n(n-1)) = \binom{n}{2}^{-1}.
  3. To succeed with probability 1-\delta, repeat O(\binom{n}{2} \ln(1/\delta)) times = O(n^2 \log(1/\delta)).
NoteProblem E7

Consider the problem of polynomial identity testing (PIT). Given two arithmetic circuits computing polynomials P and Q in n variables, each of degree d, determine if P \equiv Q as polynomials.

  1. Describe a randomized algorithm using Schwartz-Zippel.
  2. Analyze the error probability.
  3. Why is this problem believed to be hard for deterministic algorithms?
  4. Show how PIT can be used to check if a program computing a matrix determinant is correct (program checking).
TipSolution
  1. Evaluate P(r) - Q(r) at random points r \in S^n where S \subseteq \mathbb{F} of size q. By Schwartz-Zippel, error \le d/q.
  2. Error \le d/|S|.
  3. PIT is believed hard because deterministic algorithms would require derandomizing Schwartz-Zippel, which is connected to circuit lower bounds and other hard problems in complexity theory.
  4. For determinant checking: given circuit C claimed to compute \det(A), use PIT to check C(A) \cdot A = \det(A) \cdot I (matrix identity) or check against a known algorithm for small random matrices.
NoteProblem E8

Fingerprinting applications: For each of the following settings, design a randomized algorithm and analyze its error probability:

  1. Set equality: Two parties have subsets A,B \subseteq \{1,\dots,U\}. They want to check if A = B with O(\log U) communication.
  2. Multiset equality: Same as above, but duplicates matter.
  3. Pattern matching: Given text T (length n) and pattern P (length m), find all positions where P occurs in T. Use fingerprinting (Rabin-Karp). What is the worst-case complexity? What is the expected complexity?
TipSolution
  1. Set equality: Use polynomial fingerprint p_A(t) = \prod_{a \in A} (t - a). Check p_A(r) = p_B(r) for random r. Error \le |A \cup B|/q. Communication: O(\log q).
  2. Multiset: Use \sum_{a \in A} \alpha^a evaluated at random \alpha, or use polynomial with multiplicities: \prod_{a} (t-a)^{m_a}.
  3. Rabin-Karp: Hash each length-m substring of T using rolling hash. Expected O(n+m) time (worst-case O(nm) with bad hash collisions). False positive rate controlled by hash modulus size.
